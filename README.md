# 🏏 IPL Data Analysis Dashboard

## 📊 Project Overview

This project is an IPL Data Analysis Dashboard created using Microsoft Excel.

The dashboard provides insights into IPL matches, players, teams, seasons,
venues, runs, wickets and match outcomes.

## 🛠️ Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Excel Functions
- Data Visualization

## 📈 Dashboard Features

- Total Matches
- Total Runs
- Total Wickets
- Matches by Season
- Matches by Venue
- Top 10 Run Scorers
- Top 10 Wicket Takers
- Team Performance
- Match Winners
- Season-wise Analysis
